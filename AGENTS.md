# AGENTS Guidelines for This Repository

This repository contains a Golang v1.23.8 application which represents an authorisation service working with Keycloak v22 and auto-generated by Keycloak PostgreSQL database. When working on the project interactively with an agent (e.g. the Codex CLI) please follow the guidelines below so that the development experience.

## Infrastucture

- All secrets are located in hashicorp/vault
- Service is using Keycloak IAM
- Service is directly accessing data about users and sessions from PostgreSQL DB automatically generated by Keycloak
- Service is using Redis as cache

## Coding rules

- All I/O operations must have timeout defined in config. All these operations must use context with timeout
- Consts are located in internal/consts
- Config structures are located in internal/configs
- All configurable values must be set in yaml config file. All credentials must be stored in vault.
- All HTTP endpoints must use common middleware (internal/middlewares/common)
- Use mailru/easyjson for JSON marshaling
- Use fasthttp instead of default http server
- Use raw sql requests, put them in db/requests/%domain%

## Observability rules

- All errors must be logged: ERROR for unexpected (e. g. error marshaling JSON), WARN for expected (e.g. user not authorised)
- Sensitive data (such as users' tokens) must NOT be logged in any level except DEBUG
- All I/O operations must have their own time metrics
- All network requests must have their success metrics
- All GRPC requests contain trace_id in metadata
- All requests must be logged with their id

## Useful commands

- swagger-docs: update swagger documentation
- build: build project
- run: run project
- lint: run linter
- easyjson: create easyjson for all data structures
